❓ Diagnostic & Troubleshooting Assistant

Instant solutions for common installation errors and environment misconfigurations.

⚠️ "failed to parse model_catalog_json ... expected value at line 1 column 1" ▼

Root Cause: The ica-models.json file was saved with a UTF-8 Byte Order Mark (BOM: 0xEF 0xBB 0xBF). The Codex Rust JSON parser requires pure UTF-8 without BOM.

Fix: Re-save the file as pure UTF-8 (No BOM). In PowerShell, run:

PowerShell Fix 
$path = "$HOME\.codex\model-catalog\ica-models.json"
$content = Get-Content $path -Raw
$utf8NoBom = New-Object System.Text.UTF8Encoding($false)
[System.IO.File]::WriteAllText($path, $content, $utf8NoBom)
⚠️ "Missing environment variable: ICA_API_KEY" (Background Daemon Cache) ▼

Root Cause: Codex CLI uses a persistent background daemon server (Local background server). If the server was started before ICA_API_KEY was saved, it holds the old environment in memory.

Fix: Stop the background daemon and re-launch Codex. Run in PowerShell:

PowerShell Fix 
Get-Process -Name 'codex', 'node_repl' -ErrorAction SilentlyContinue | Stop-Process -Force
$env:ICA_API_KEY = [System.Environment]::GetEnvironmentVariable('ICA_API_KEY', 'User')
codex
⚠️ Windows: "codex cannot be loaded because running scripts is disabled" ▼

PowerShell execution policy is blocking script execution. Run the following command in PowerShell, or run codex.cmd instead:

PowerShell 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
⚠️ /status shows "openai" instead of "ica" ▼

This happens if the 4 top-level settings in config.toml were placed below a [section] header or the catalog path has unescaped backslashes.

Ensure these lines appear at the very top of ~/.codex/config.toml:

config.toml (Top of file) 
model = "gpt-advantage-assist"
model_provider = "ica"
model_catalog_json = "C:\\Users\\YOUR_USERNAME\\.codex\\model-catalog\\ica-models.json"
model_reasoning_effort = "medium"

Or override temporarily via CLI: codex --config 'model_provider="ica"' --model gpt-advantage-assist

⚠️ Windows: Files saved with .txt extension (e.g. .env.txt or ica-models.json.txt) ▼

Notepad automatically appends .txt if not saved as "All Files".

Fix: In File Explorer, enable View > Show > File name extensions, then rename the file to remove the trailing .txt. Or use the automation script to create files accurately.

⚠️ macOS: npm shows EACCES permission error during global install ▼

Avoid using sudo. Configure npm to store global packages inside your home directory:

Terminal (Zsh) 
mkdir -p "$HOME/.npm-global"
npm config set prefix "$HOME/.npm-global"
echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
npm install -g @openai/codex
⚠️ "Metadata not found" warning in terminal ▼

This is a known cosmetic warning in current Codex CLI versions when reading custom model catalogs. As long as /status shows provider: ica and the hello prompt succeeds, this warning can be safely ignored.
